LN Architektura & Wnętrza – prototyp strony

Jak uruchomić:
1. Rozpakuj ZIP.
2. Otwórz plik index.html w przeglądarce.

Co jest w paczce:
- index.html – struktura strony
- styles.css – cały wygląd premium
- script.js – menu, animacje, sticky header
- assets/ – wyłącznie assety pobrane ze strony lnwnetrza.pl

Publikacja:
Wgraj wszystkie pliki na hosting do katalogu public_html albo użyj Netlify/Vercel jako statycznej strony.
